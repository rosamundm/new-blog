Welcome to the repo for my website (which contains a blog). It runs on Django with a Wagtail CMS. The frontend is rendered via template; no API here.

You can simply create a virtual environment, `cd app && pip install -r requirements.txt` et voilà.

Thanks to [Wagtail Bakery](https://github.com/wagtail/bakerydemo) for providing some of the basic elements to get started with.
